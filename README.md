# Pawfect Studio London

Public hosting package for the Pawfect website demonstration.

The editable React and TypeScript source is kept privately. This repository
contains only the production static website archive and its publishing workflow.
The archive contains the same HTML, CSS, JavaScript, fonts and images delivered
to website visitors. Source maps and editable application sources are excluded.

GitHub Actions extracts `pawfect-static.zip` and publishes it to GitHub Pages.

Booking is a demonstration only. No real appointments, payments or confirmation
messages are created. Grooming portraits and the labelled comparison are
AI-generated concepts, not actual salon results.
